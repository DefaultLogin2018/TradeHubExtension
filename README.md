Расширение для для Chrome/Opera (Тестировалось на этих двух браузерах).<br>
Функцонал:<br>
-Создание Hub вкладки при работе с трейдингом на сайте Path of Exile 2 Trade<br>
-Мониторинг всех предметов при Live Search на любой из вкладок(или на всех сразу).<br>
-Возможность получения информации, такой как 'whisper' формата:<br> '@nickname whisper', получаемой при обработке xhr запросов после соединения с websocket.<br>



Как реализован функцонал:<br>
-Инъектирование script'a (injected.js в проекте) в код страницы сайта Path of Exile 2 / trade <br>
-После инъекции мы получаем возможность "слушать" websocket-соединение / xhr / fetch запросы.<br>
-На странице Хаба - отрисовываются внутриигровые предметы, которые выставляюся на продажу (сейчас верстка требует доработки).<br>
-Так же с сопоставлением ID отрисованного объекта - идет поиск запроса, который возвращает данные о предмете , отрисовывается информация доступная только в запросе и отсутствующая в верстке.<br>
